# Getting help

* **How do I install / use it?** [README](README.md), [docs/install.md](docs/install.md).
* **A site renders wrong or does not work:** open a *Site compatibility* issue. Check [docs/compat.md](docs/compat.md) first;
  some things (DRM, extensions, WebRTC, WebAssembly) are known gaps.
* **A bug:** open a *Bug report* issue.
* **A slow page or a regression:** open a *Performance* issue with numbers.
* **A question or an idea:** start a GitHub Discussion, or open a *Feature request* if it is concrete.
* **A security problem:** [SECURITY.md](SECURITY.md). Never a public issue.
